# My FlyRank AI Internship Journey: Final Retrospective

**Name:** Piasa Das  
**Role:** Machine Learning Engineering Intern  
**Organization:** FlyRank AI  
**Duration:** 2026

## 1. My Starting Point

When I started the FlyRank AI internship, my main goal was to gain practical knowledge of Machine Learning and understand how AI is used to solve real-world problems. As a Data Science student, I had learned theoretical concepts, but I wanted to improve my practical skills and gain experience working on a real project.

In the beginning, I was still developing my confidence in Python, machine learning workflows, and model evaluation. I wanted to understand how a machine learning project moves from a research question to a working solution.

## 2. What I Worked On

Throughout the internship, I completed different weekly assignments covering research questions, machine learning task framing, data contracts, feature leakage checks, signal audits, baseline scoring, model development, and validation.

My main capstone project was **Content Refresh Prioritization Using Machine Learning**.

The project focused on identifying website pages that might need content updates or improvements. I worked with anonymized content data and explored different signals to understand which pages should receive attention first.

I developed a baseline prioritization approach and explored machine learning models to improve the ranking process. I also worked on model evaluation, Precision@k, feature leakage checks, and validation.

One important part of my learning was understanding that a good model is not just about achieving a high score. The data, target definition, validation strategy, and business relevance are equally important.

## 3. What Changed During the Internship

At the beginning, I mainly focused on writing code and getting the expected output. Gradually, I started thinking more critically about why a particular method was being used and whether the results were reliable.

I learned that machine learning is not simply about training a model. It requires understanding the problem, preparing the data, selecting meaningful features, comparing against a baseline, and checking whether the evaluation results can be trusted.

I also became more comfortable using Google Colab, GitHub, Python libraries, and AI assistants as part of my development workflow.

The internship improved my ability to approach problems step by step instead of trying to solve everything at once.

## 4. Three Most Transferable Things I Learned

**1. Problem Framing and Data Understanding**

I learned that understanding the problem and the dataset is the foundation of a successful machine learning project. A model cannot produce meaningful results if the research question or target is poorly defined.

**2. Model Evaluation and Validation**

I learned the importance of evaluating models using suitable metrics such as Precision@k. I also understood why feature leakage and inappropriate validation methods can produce misleading results.

**3. Using AI as a Development Partner**

I learned how AI tools can support coding, debugging, research, documentation, and learning. However, AI-generated outputs still need to be checked and understood. AI is most useful when it supports independent thinking rather than replacing it.

## 5. What I Would Build Next

In the future, I would like to improve my content prioritization project by testing it on additional datasets, exploring more machine learning approaches, and improving the reliability of its recommendations.

I also want to develop stronger skills in Python, SQL, statistics, machine learning, and deep learning. My long-term goal is to become a skilled Machine Learning Engineer and work on practical AI-driven solutions.

## 6. Final Reflection

Looking back at my first week, I can see how much my understanding of machine learning workflows has improved.

This internship gave me an opportunity to move beyond theoretical learning and apply concepts through practical assignments and a capstone project.

I learned that building a reliable machine learning solution requires patience, experimentation, critical thinking, and continuous improvement.

My biggest takeaway is that a successful data science project is not only about building a model. It is about understanding the problem, making responsible decisions, evaluating results honestly, and communicating the outcome clearly.

I consider this internship an important step in my journey as a Data Science student and aspiring Machine Learning Engineer.

**Thank you, FlyRank AI, for this learning opportunity.**
